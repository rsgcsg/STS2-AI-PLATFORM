# Status

This component is part of `STS2-AI-PLATFORM`. It is not a separate forward
development repository. The stable compatibility term `headless` remains in
the CLI and runtime identity.

Verdict: **source/package candidate; runtime seal is not claimed.**

## Current Identity Authority

Read current component versions, source revisions, package checksums, protocol,
exact-game audit, and non-claims from the root `platform-bom.json` and the
Connector `release-manifest.json`. This file deliberately does not duplicate
those values. The installed and loaded identities must be recorded by the
current runtime verifier; source/package facts do not imply either state.

## Current Scope

- Host Runtime owns executable discovery, exact-build admission, no-display
  launch, profile lifecycle, health, reset, recovery, worker supervision, and
  Host evidence.
- The Platform Connector component owns the fair-player Snapshot/Read,
  BoundAction, native binding, Receipt, successor, and Connector identity.
- STS2 owns rules, RNG, legality, effects, tasks, commands, saves, and Commit.
- Consumers own strategy, projection, rewards, search, and learning.

## Candidate Evidence

Portable checks and package checks can prove source/test/package behavior. Local
exact-game build, install, boot, loaded identity, mutation, journey, human
validation, and qualification are separate gates. Dated reports from
predecessor repositories are history/rollback evidence and cannot qualify the
current Platform candidate.

## Non-claims

- No current Platform artifact is claimed installed, loaded, Live-exercised,
  human-validated, or qualified here.
- No universal game-version, Modset, platform, content, soak, or H1.0 claim is
  made without a matching current identity and named evidence.
- A delivery Receipt proves input delivery, not inferred business completion.
- Hidden state, coordinate input, arbitrary reflection mutation, and a second
  gameplay rules engine are outside this component.

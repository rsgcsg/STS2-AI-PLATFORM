## Closed defects

1. Relics, potions, and run modifiers previously exported only a hover-tip
   count. Any non-empty tooltip therefore erased the whole canonical
   persistent state. The exact Host now converts game-owned `HoverTip` and
   `CardHoverTip` values into visible keyword and card-preview facts. Unknown
   tip types remain explicitly incomplete.
2. The public interaction context leaked relic native identities even though
   execution operands are required to remain Host-local. One public sanitizer
   now strips native identity, binding, target, extraction-diagnostic, and
   dynamic-variable fields from both relics and potions.
3. Managed rest options used CLR type names and omitted native visible
   descriptions. They now use the exact option `Title`, `Description`, and
   `IsEnabled` values used by the game-owned rest interaction.
4. Several already-supported treasure, reward-completion, shop, and generic
   interactions lacked explicit visible-information and discovery provenance,
   causing false partial verdicts. Their same-interaction observation and
   execution basis is now recorded directly.
5. The probe always labeled successful evidence `partial`. It now derives the
   status and performance unit from every recorded canonical decision plus the
   final successor while retaining the explicit `unqualified` boundary.

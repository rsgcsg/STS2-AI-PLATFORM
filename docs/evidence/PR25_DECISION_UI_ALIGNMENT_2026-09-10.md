   cancel/confirm/skip, visible pile provenance and finite candidates. Training

   catalogs are evidence; live mutation still uses the current Connector public
   catalog. Parent S' may be the selector input state, not completed card effect.
4. Admit a bounded Human corpus before annotation/training. Human behavior is
   not automatically the optimal label. Gold tasks must bind the same state,

## Frozen production route

Native Foundation remains compiled into the unified `STS2_PLATFORM` Mod.
Platform owns semantic catalogs, exact validators, action lifecycle/lineage,
Connector delivery authority, Annotator correlation, Host lifecycle, and exact
game/Modset qualification. Production has no Ritsu package, Mod dependency,
bootstrap, fallback profile, or second configuration fingerprint.

Reopen only when a future stable Ritsu release replaces a critical Platform
seam across at least two real production domains, deletes meaningful Direct
integration rather than wrapping it, passes the same Platform conformance and
fail-closed contracts, and then passes an exact strict-config build/runtime A/B
without transferring predecessor evidence.

This decision does not characterize Ritsu as unsafe or unsuitable for general
STS2 Mod development. It only rejects a production runtime dependency for the
current Platform contract.
